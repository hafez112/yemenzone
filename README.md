# 🚀 منصة يمن زون — Yemen Zone

منظومة تجارة إلكترونية متكاملة (SaaS): متاجر + إيجارات + فنادق + خدمات.

## ✅ الجلسات المنجزة
- **الجلسة 1:** Monorepo + NestJS + PostgreSQL (50 نموذج) + Docker + Seed
- **الجلسة 2:** المصادقة الكاملة + الحماية المتكاملة + الأشرطة العلوية والسفلية
- **الجلسة 3:** الواجهة الرئيسية 2027 + 5 أنماط تصميم + 4 قوالب متاجر + سلايدر ديناميكي
- **الجلسة 4:** لوحة البائع الذكية + معالج إنشاء متجر + ذكاء اصطناعي محلي + 6 تصنيفات منتجات
- **الجلسة 5:** إدارة الأصناف والمنتجات + صور WebP + واجهة المتجر بالقوالب الأربعة + ذكاء محلي شامل
- **الجلسة 6:** صفحة المنتج + فلتر شامل + سلة وطلبات + تأكيد واتساب + خصوصية وشروط لكل متجر + لوحة العميل
- **الجلسة 7:** أنظمة الإيجارات والفنادق والخدمات: لوحات متخصصة + حجوزات بالتواريخ + تأكيد واتساب
- **الجلسة 8:** لوحة العميل الشاملة + التقييمات والإعجابات + محرك الدرجة الذكية + شهادة التوثيق + نصائح AI للبائع
- **الجلسة 9:** لوحة الإدارة العليا: إحصائيات حية + إدارة متاجر/عملاء + توثيق + إشراف تقييمات وإيجارات وفنادق وخدمات
- **الجلسة 10:** نظام الخطط والاشتراكات والكوبونات: ترقية مدفوعة بفواتير INV + كوبونات خصم في السلة + إدارة خطط كاملة للإدارة
- **الجلسة 11:** نظام التوصيل: لوحة سائق PWA + تعيين ذكي بالذكاء المحلي + شركات توصيل وربطها بالمتاجر + إصلاح شامل لأخطاء البناء (API + Web يُبنيان بنجاح)
- **الجلسة 12:** مركز المراسلة: قوالب SMS/واتساب لكل الأحداث + مزودو خدمة + إرسال حقيقي/محاكاة + سجل رسائل + إشعارات تلقائية (طلب جديد/تحديث/حجز/اشتراك/سائق) + صفحة طلبات البائع
- **الجلسة 13:** نظام المدفوعات: بوابات يمنية (بنوك/محافظ) + اختيار طريقة الدفع بالسلة + رفع إثبات التحويل + مركز مراجعة بكشف التلاعب الذكي + تأكيد تلقائي للطلب
- **الجلسة 14:** البطاقات والمحافظ: توليد بطاقات شحن قابلة للطباعة + بطاقة العميل وشحنها الفوري + الدفع بالبطاقة برمز OTP + محفظة التاجر وطلبات السحب
- **الجلسة 15:** المركز المالي: عملات وأسعار صرف + عمولة المنصة + رسوم إيرادات 6 أشهر مع تنبؤ ذكي + تقرير مبيعات التاجر مع نصائح نمو
- **الجلسة 16:** مركز الأمن: تحليل تهديدات محلي (درجة 0-100) + كشف IP المشبوهة + حظر يدوي/مؤقت + أجهزة موثوقة + مديرون متعددون بصلاحيات دقيقة على كل مسارات الإدارة
- **الجلسة 17:** API العام للمطورين: مفاتيح مشفرة (sha256) بصلاحيات وحدود استخدام + 6 نقاط عامة (متجر/منتجات/طلبات) + عدادات يومية + تحليل استخدام ذكي + توثيق تفاعلي مع اختبار مباشر
- **الجلسة 18:** إدارة التصميم الديناميكي: هوية وألوان فورية + شريط إعلان + تبديل أقسام الرئيسية + سلايدر + نسخ احتياطية واستعادة + صفحات مخصصة HTML بروابط /p + خدمات منصة مدفوعة بطلبات وإثباتات دفع
- **الجلسة 19:** المتاجر القريبة (GPS + ترتيب ترشيح ذكي) + نظام الشكاوى (تقديم/تتبع/رد بتصنيف آلي وردود مقترحة) + SEO متكامل (sitemap ديناميكي + robots + JSON-LD + OpenGraph)
- **الجلسة 20 (الختامية):** نسخ احتياطي كامل (تصدير 48 جدول JSON + تحميل + نصائح صحّة ذكية) + تطبيق PWA (تثبيت على الجوال + عمل دون اتصال) + حجم Docker للنسخ — المنصة مكتملة 100% 🎉

## 🛡️ مركز الأمن (الجلسة 16)

- **تحليل التهديدات المحلي 🤖:** درجة تهديد 0-100 من سجلات آخر 24 ساعة (إخفاقات الدخول/OTP + أنماط مشبوهة + نشاط فجراً) دون أي خادم خارجي
- **كشف المشتبه بهم:** IP بـ 5+ محاولات فاشلة أو 3+ أنواع أحداث — مع زر حظر فوري من النظرة العامة
- **حظر IP يدوي:** دائم أو مؤقت (بالأيام) + رفع الحظر — والحظر التلقائي من نظام المصادقة يظهر هنا أيضاً
- **الأجهزة الموثوقة:** اعتماد/حظر أجهزة لوحة الإدارة
- **مديرون متعددون 👮:** المشرف العام يضيف مديرين بصلاحيات دقيقة (12 صلاحية: المتاجر/العملاء/التقييمات/الإشراف/الخطط/التوصيل/المراسلة/المدفوعات/البطاقات/المالية/الأمن/التصميم)
- **حارس الصلاحيات `PermsGuard`:** يتحقق من قاعدة البيانات في كل طلب — مطبق على جميع مسارات الإدارة الحساسة، والمشرف العام (`isSuper` أو صلاحية `*`) يتجاوز تلقائياً
- **سجل أمني موحد:** كل حدث حساس (دخول/حظر/تعديل مدير/جهاز) يُسجل مع IP والتفاصيل
- **حماية المشرف العام:** لا يمكن حذفه أو تعليقه، ولا يحذف المدير حسابه بنفسه


## 🔑 API العام للمطورين (الجلسة 17)

- **مفاتيح آمنة:** توليد `yzk_` + 48 حرفاً عشوائياً، يُخزن **sha256 فقط** ويظهر المفتاح الكامل مرة واحدة عند الإنشاء
- **صلاحيات دقيقة (Scopes):** `store:read` · `products:read` · `orders:read` · `orders:write` — كل نقطة تتطلب صلاحيتها
- **حدود الاستخدام:** نافذة منزلقة 60 ثانية لكل مفتاح (10-600 طلب/دقيقة، حسب اختيار التاجر مع اقتراح ذكي حسب نوع المتجر)
- **النقاط العامة** `/api/open-api/v1` (ترويسة `x-api-key`):
  | النقطة | الصلاحية | الوظيفة |
  |---|---|---|
  | `GET /ping` | أي مفتاح | فحص الاتصال |
  | `GET /store` | store:read | بيانات المتجر وعداداته |
  | `GET /products` | products:read | قائمة المنتجات مع بحث وترقيم |
  | `GET /products/:id` | products:read | تفاصيل منتج |
  | `POST /orders` | orders:write | إنشاء طلب (السعر من الخادم) |
  | `GET /orders/track` | orders:read | تتبع طلب برقمه وجوال العميل |
- **عدادات يومية:** كل طلب يُحسب في `ApiUsage` (نجاح/فشل) مع إجمالي تراكمي وآخر استخدام
- **تحليل الاستخدام الذكي 🤖:** كشف الارتفاع المفاجئ (ضعف متوسط الأسبوع)، معدل الفشل المرتفع (>20% = تكامل خاطئ أو تخمين)، المفاتيح الخاملة 14+ يوم، اقتراح رفع الحد — كل ذلك محلياً دون خوادم خارجية
- **توثيق تفاعلي:** صفحة `/seller/api` فيها أمثلة cURL جاهزة بالنسخ + اختبار ping مباشر من المتصفح
- **أمان إضافي:** المفتاح الموقوف أو متجر غير نشط = رفض فوري، حد أقصى 10 مفاتيح نشطة لكل متجر


## 🎨 التصميم الديناميكي والمحتوى (الجلسة 18)

- **إدارة تصميم كاملة** من `/admin/design` (صلاحية `design`):
  - **الهوية:** اسم المنصة والشعار وواتساب والبريد + **شريط إعلان** يظهر أعلى كل الصفحات
  - **الألوان:** 5 أنماط جاهزة + منتقي ألوان مع معاينة حية — يُطبق اللون الأساسي فوراً على المنصة كلها عبر CSS variables
  - **الأقسام:** إظهار/إخفاء 7 أقسام بالرئيسية (Hero/سلايدر/مميزات/قوالب/أسعار/متاجر/دعوة) بضغطة
  - **السلايدر:** إضافة/تعديل/إخفاء/حذف الشرائح
  - **نسخ احتياطية:** تصوير كامل للإعدادات والشرائح مع استعادة بضغطة (نموذج `ThemeBackup`)
- **الصفحات المخصصة 📄:** محرر HTML حر في `/admin/pages` — رابط `/p/{slug}`، ظهور بالقائمة العلوية أو التذييل، حقول SEO (عنوان/وصف)، عداد مشاهدات، وترتيب — مع أنماط عرض جاهزة (عناوين/قوائم/اقتباسات)
- **خدمات المنصة 🧩:** خدمات مدفوعة تعرضها المنصة (تصميم شعار/تصوير/حملات) — صفحة عامة `/services` بطلب + إثبات تحويل عبر البوابات، ومراجعة إدارية تسجّل الإيراد تلقائياً في المركز المالي (`pservice`) — خدمة عليها طلبات تُعطّل بدل الحذف حفاظاً على السجل
- **الذكاء المحلي 🤖:** تحذير تباين اللون (لمعان W3C)، طول الإعلان، غياب الشرائح، صفحات بلا SEO، تحليل طلبات الخدمات (الأكثر طلباً/المعلقة/الخاملة/الإيراد)
- **بذور جاهزة:** صفحات (من نحن/تواصل/أسئلة شائعة) + 4 خدمات افتراضية


## 📍 المتاجر القريبة والشكاوى وSEO (الجلسة 19)

- **المتاجر القريبة `/nearby`:** زر "حدّد موقعي" (Geolocation) → حساب المسافات بمعادلة هافرساين، وترتيب بدرجة ترشيح ذكية: المسافة بتحلل أسّي (50%) + التقييم (25%) + الدرجة الذكية (15%) + التوثيق (10%) — مع شارات (📍 الأقرب / ⭐ الأعلى تقييماً / 🏆 ترشيحنا الذكي) وفلاتر محافظة ونوع، ويعمل بدون GPS بالترتيب المحايد
- **الشكاوى 📣:**
  - تقديم عام `/complaint` (زائر أو عميل) → رقم تتبع `CMP-XXXXXX` — منع تكرار نفس الشكوى خلال ساعة
  - تتبع `/complaint/track` بالرقم والجوال مع شريط مراحل ورد الإدارة
  - إدارة `/admin/complaints` (صلاحية `customers`): **تصنيف آلي** (توصيل/دفع/متجر/تقني بالكلمات المفتاحية) + **أولوية عالية** لكلمات الاستعجال + **رد مقترح جاهز** لكل تصنيف + إغلاق/إعادة فتح + ترتيب ذكي (عالية ومفتوحة أولاً)
- **SEO متكامل:**
  - `sitemap.xml` ديناميكي: الصفحات الثابتة + كل المتاجر (مع صفحات منتجاتها) + الصفحات المخصصة — يتجدد كل ساعة
  - `robots.txt`: يمنع فهرسة لوحات التحكم (/admin /seller /customer /driver) ويسمح بالعام
  - بيانات JSON-LD منظمة لكل متجر (Store + GeoCoordinates + AggregateRating) لنتائج بحث غنية
  - OpenGraph + Twitter Cards + عنوان قالب `%s | يمن زون` + metadataBase


## 💾 النسخ الاحتياطي وPWA (الجلسة 20)

- **النسخ الاحتياطي `/admin/backups`** (صلاحية `security`):
  - تصدير **48 جدولاً** كاملاً بملف JSON واحد بضغطة زر — بدون اعتماد على pg_dump
  - قائمة النسخ بالحجم والتاريخ وملاحظات + **تحميل آمن** (بتوكن الإدارة) + حذف
  - كشف الملفات المفقودة من القرص + حماية path traversal
  - **نصائح صحّة ذكية 🤖:** عمر آخر نسخة (تحذير 48س/خطر أسبوع)، نمو الحجم، أكبر الجداول، تذكير بالتخزين الخارجي
  - مجلد `yz_backups` منفصل في Docker — تبقى النسخ عند إعادة بناء الحاويات
- **تطبيق PWA 📱:**
  - `manifest.json` عربي RTL كامل + أيقونات مولّدة (192/512/maskable)
  - **Service Worker:** أصول ثابتة من الكاش، صفحات بشبكة-أولاً مع بديل مخبأ، و`/v1/theme` يعمل دون اتصال
  - قابل للتثبيت على الجوال كتطبيق مستقل (standalone) مع دعم iOS (appleWebApp)
