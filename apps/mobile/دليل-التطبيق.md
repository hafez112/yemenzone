# 📱 تطبيق يمن زون لأندرويد — الدليل الكامل

تطبيق أندرويد **أصلي** (حزمة `com.yemenzone1.app`) مبني بـ Capacitor، يغلّف منصتك الحية مباشرة.
**الميزة الكبرى**: أي تحديث تنشره للموقع يظهر في التطبيق فوراً — لا حاجة لإعادة بنائه أبداً إلا لتغيير الأيقونة أو الاسم.

كل البناء يحدث **سحابياً في GitHub Actions** — لا تحتاج حاسوباً إطلاقاً، كل شيء من Termux.

---

## 🚀 الخطوة 1: ارفع المشروع إلى GitHub (مرة واحدة)

من Termux في مجلد المشروع:

```bash
cd ~/yemen-zone
git init
git add .
git commit -m "يمن زون — المنصة + تطبيق أندرويد"
git branch -M main
```

أنشئ مستودعاً جديداً في github.com (اسمه مثلاً `yemen-zone` — اجعله Private)، ثم:

```bash
git remote add origin https://github.com/اسمك/yemen-zone.git
git push -u origin main
```

> إن طلب كلمة مرور: أنشئ Personal Access Token من GitHub → Settings → Developer settings → Tokens (classic) بصلاحية `repo`.

## 📦 الخطوة 2: حمّل التطبيق الجاهز

1. افتح المستودع في المتصفح → تبويب **Actions**.
2. ستجد «📱 بناء تطبيق أندرويد» يعمل تلقائياً (أو شغّله يدوياً: Run workflow).
3. بعد اكتماله (3-5 دقائق) افتحه → قسم **Artifacts** → حمّل `yemen-zone-app-debug-apk`.
4. فك ضغط الملف في هاتفك → ثبّت `app-debug.apk` (اسمح بالتثبيت من مصادر خارجية عند الطلب).

🎉 التطبيق يعمل الآن بهوية يمن زون الكاملة: أيقونة، شاشة بداية، وفتح روابط yemenzone1.com داخله تلقائياً.

## 🏪 الخطوة 3: النشر في جوجل بلاي (اختياري — 25$ لمرة واحدة)

### أ) أنشئ مفتاح التوقيع في Termux (مرة واحدة — احفظه بأمان!):

```bash
pkg install openjdk-17 -y
keytool -genkey -v -keystore yemenzone.keystore -alias yemenzone -keyalg RSA -keysize 2048 -validity 10000
base64 yemenzone.keystore | tr -d '\n' > ks.txt && cat ks.txt
```

> ⚠️ مفتاح `yemenzone.keystore` هو هوية تطبيقك للأبد — احتفظ بنسخة منه في مكان آمن. فقدانه = عجز دائم عن تحديث التطبيق في بلاي.

### ب) أضف الأسرار في GitHub:

المستودع → **Settings → Secrets and variables → Actions**:

| النوع | الاسم | القيمة |
|---|---|---|
| Secret | `KEYSTORE_BASE64` | محتوى ملف ks.txt كاملاً |
| Secret | `KEYSTORE_PASSWORD` | كلمة مرور المفتاح |
| Secret | `KEY_ALIAS` | `yemenzone` |
| Secret | `KEY_PASSWORD` | كلمة مرور المفتاح نفسها |
| Variable (تبويب Variables) | `KEYSTORE_CONFIGURED` | `true` |

### ج) أعد تشغيل الـworkflow من تبويب Actions — سيظهر artifact جديد `yemen-zone-release-aab`.

### د) في Play Console (play.google.com/console):

1. أنشئ حساب مطور (25$ تُدفع مرة واحدة في العمر).
2. أنشئ تطبيقاً جديداً باسم «يمن زون».
3. ارفع ملف AAB في قسم الإصدار، وأكمل بيانات صفحة المتجر بالنصوص الجاهزة في القسم التالي، وأجب استبيانات المحتوى.
4. أرسل للمراجعة — تستغرق عادة 3-7 أيام.

### إجابات استبيان «أمان البيانات» (Data safety)
- **هل يجمع التطبيق بيانات؟** نعم: الاسم، رقم الجوال، العنوان، سجل الطلبات — لغرض تشغيل الطلبات والحجوزات فقط.
- **هل تُشارك البيانات مع طرف ثالث؟** لا.
- **هل البيانات مشفّرة أثناء النقل؟** نعم (HTTPS).
- **هل يمكن طلب حذف البيانات؟** نعم — عبر التواصل من صفحة الحساب أو واتساب الدعم.
- **الإذونات المطلوبة**: إنترنت فقط (+ اهتزاز لمسي خفيف) — لا موقع، لا جهات اتصال، لا كاميرا إجبارية.

### ملاحظة: الروابط العميقة (assetlinks)
التطبيق يفتح روابط yemenzone1.com تلقائياً. بعد تفعيل **Play App Signing** في Play Console:
1. خذ بصمة SHA-256 من Play Console → Setup → App integrity.
2. أرسلها لي لأولّد لك ملف `assetlinks.json` — حينها تفتح الروابط داخل التطبيق مباشرة دون سؤال المستخدم.

## 🔧 تحديث نسخة التطبيق لاحقاً

عند رفع إصدار جديد لجوجل بلاي، زد الرقمين في `apps/mobile/android/app/build.gradle`:

```gradle
versionCode 2        // رقم داخلي — يزيد 1 مع كل إصدار
versionName "1.1"    // يظهر للمستخدمين
```

## 💡 ملاحظات

- التطبيق يحتاج اتصال إنترنت (يعرض المنصة الحية) — وهذا مقصود ليبقى محدثاً دائماً.
- إشعارات التطبيق الفورية (Push) يمكن إضافتها لاحقاً عبر Firebase عند الحاجة.
- وصف جيد ولقطات شاشة حقيقية في صفحة بلاي يضمنان قبولاً سريعاً.
